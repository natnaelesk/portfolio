# Natnael Esk — Portfolio (v2)

Minimalist portfolio built with Vite, React, and Tailwind CSS.

## Branches

- `main` / `v2` — current portfolio
- `v1` — previous portfolio version

## Local development

```bash
npm install
npm run dev
```

## Deploy

Hosted on [Vercel](https://vercel.com). Pushes to `main` or `v2` deploy automatically.
